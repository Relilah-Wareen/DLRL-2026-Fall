\textbf{Method (a), (c).}
For each $s\in\{5,2,1\}$, set $\beta=\sqrt{s}\,e_1$, $n=200$, and use
\[
 p\in\{20,40,60,80,100,120,140,160,180,199,200,220,240,260,300,400,600\}.
\]
For every $(s,p)$, perform 20 independent repetitions. In each repetition,
draw fresh, mutually independent $X\in\mathbb R^{200\times p}$,
$\varepsilon\in\mathbb R^{200}$, and $X_{\rm test}\in\mathbb R^{2000\times p}$
with independent standard Gaussian entries. Form $y=X\beta+\varepsilon$,
compute the minimum-norm solution $\widehat\beta=X^+y$ using
\texttt{numpy.linalg.lstsq}, and record
\[
 R=\frac1{2000}\|X_{\rm test}(\widehat\beta-\beta)\|_2^2.
\]
The test target is noiseless, as specified. The random seed is 20260914;
\texttt{results/risks.csv} contains all 1,020 risks.

\section*{Problem 2: Asymptotically valid inference for averaged SGD}

\textbf{(a) Gradient, Hessian, and minimizer.}
Set $u=x^\top\theta$. Differentiating the logistic loss gives
\[
\nabla_\theta\ell=(\sigma(u)-y)x,
\qquad
\nabla_\theta^2\ell=\sigma(u)(1-\sigma(u))xx^\top.
\]
Indeed, $d\log(1+e^u)/du=\sigma(u)$ and
$\sigma'(u)=\sigma(u)(1-\sigma(u))$.
Under the stipulated Bernoulli model,
\[
\nabla L(\theta^\star)
=\mathbb E[(\sigma(X^\top\theta^\star)-Y)X]
=\mathbb E[\{\sigma(X^\top\theta^\star)
-\mathbb E(Y\mid X)\}X]=0.
\]
The Gaussian covariate has positive-definite covariance
$\Sigma_X$ (eigenvalues $0.6$ and $1.4$). For any nonzero $v$,
\[
v^\top\nabla^2L(\theta)v
=\mathbb E[\sigma(X^\top\theta)(1-\sigma(X^\top\theta))
(v^\top X)^2]>0,
\]
since the logistic factor is positive and $v^\top X$ is a nondegenerate
Gaussian. Gaussian moments justify differentiation under the expectation.
Thus $L$ is strictly convex, and its stationary point $\theta^\star$
is its unique minimizer. The contrast is
$\psi^\star=c^\top\theta^\star=-1/\sqrt5$.

\textbf{(b) Online computation.}
Each of 500 independent outer replications generates one fresh
$X_t\sim N(0,\Sigma_X)$ and one conditional Bernoulli $Y_t$ at each
$t=1,\ldots,10000$. The observed SGD path starts at zero and uses
$\eta_t=1.6(t+10)^{-0.6}$. Within a replication, all 200 bootstrap paths
use this same data stream and independent $\operatorname{Exp}(1)$
multipliers. We retain $\theta_t$ only for $t>200$ and evaluate all
three stated intervals at the five specified checkpoints. For the
plug-in interval, we accumulate the full Hessian and outer products of
the gradients computed at $\theta_{t-1}$. We evaluate
$c^\top\widehat H_T^{-1}\widehat S_T\widehat H_T^{-1}c$
without replacing the sandwich by $\widehat H_T^{-1}$.
For random scaling, if $P_s=\sum_{j=1}^s c^\top\vartheta_j$, we compute
\[
\widehat r_T=\frac1{n_T^2}\sum_{s=1}^{n_T}
(P_s-s\widehat\psi_T)^2,
\]
which is algebraically the stated formula. All calculations use
double precision. Outer replication $r$ uses seed $20260923+r-1$;
results and individual intervals are saved in the accompanying CSV files.
